GitHub 연결

작품 삭제를 위해 이 저장소에 쓸 수 있는 GitHub 토큰을 연결해 주세요. 토큰은 이 페이지를 닫거나 새로고침하면 사라집니다.

처음 연결하나요?

GitHub에서 토큰 만들기 → 소유자 kalapui36 → 저장소 linkday만 선택 → Contents 권한을 Read and write로 설정하세요. 생성한 값은 위 입력란에만 붙여 넣으세요.

비밀번호는 관리 화면 잠금용이며, 실제 GitHub 변경 권한은 토큰으로 확인합니다.
